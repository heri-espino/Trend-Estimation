# Research decisions — Numerical Methods

**Current independent numerical study:**

1. Treat each forecast-loss function \(F(S)\) over \(S\in[0,1]\)
   as a specified numerical optimization problem.
2. Investigate analytic derivatives, adaptive root search,
   extrema classification, exact endpoints and objective ranking.
3. Use reproducible dense references for empirical tests,
   but never confuse such evidence with a root-completeness theorem.
4. Study Sturm/root isolation only for explicitly rationalized,
   manageable polynomial stationary equations.
5. Keep time-indexed branches, correspondence and dynamic
   forecasting decisions outside this manuscript.
6. Preserve the earlier benchmark protocols and results.
