# Legacy S&P 500 manuscript assets

This directory contains the earlier S&P 500 comparison manuscript, sections, scripts, figures, tables, and reproducibility assets.

It is retained as historical/source material only. It is **not** a canonical paper directory and should not receive new research work unless the maintainer explicitly reactivates it.

Canonical manuscript directories now follow the `paper_<short-title>/` convention:

- `../paper_forecast-optimal-smoothing/` — active paper.
- `../paper_penalized-trend-tutorial/` — tutorial companion.

Reusable estimators, validation logic, numerical methods, and metrics belong in `../src/trend_estimation/`.

Internal derivations/checkpoints belong in `../notes/`.
