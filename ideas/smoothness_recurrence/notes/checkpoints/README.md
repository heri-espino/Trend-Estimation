# Checkpoints

Checkpoints are chronological handoffs, not replacements for the canonical
objective or roadmap.

Each substantive stage should create

`YYYY-MM-DD_<short-description>.md`

with:

1. objective;
2. exact Git commit and command;
3. data/protocol;
4. what changed;
5. results;
6. interpretation;
7. failures/negative findings;
8. next action.

Read `../research_objective.md`, `../decisions.md`, and
`../roadmap.md` before acting on a checkpoint.
