# Checkpoints

This directory records frozen project states for the active numerical paper.

The purpose is to make the research state recoverable without reconstructing it
from Git history or old chats. A checkpoint should state:

- what question the paper currently answers;
- what evidence is already frozen;
- what has changed since the previous checkpoint;
- what remains unresolved;
- which experiments/results must not be silently retuned.
